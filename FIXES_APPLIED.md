## 🚀 How to Deploy Fixes

### 1. Install Updated Dependencies
```bash
pip install -r requirements.txt
```

### 2. Update .env
```bash
cp .env.example .env
# Edit .env with your settings
# Generate API key if needed:
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 3. Start Services
```bash
# Terminal 1: Ollama
ollama serve

# Terminal 2: Backend with logging
python server.py
# Output: Logs to friday_server.log

# Terminal 3: Frontend
cd friday-hud
npm run dev

# Terminal 4: Desktop client (optional)
python voice.py
# Output: Logs to friday_brain.log
```

### 4. Access with Authentication
```javascript
// Browser: Pass token in URL or localStorage
const token = "YOUR_API_KEY_FROM_.env";
localStorage.setItem('friday_token', token);
// Open: http://localhost:5173/
```
